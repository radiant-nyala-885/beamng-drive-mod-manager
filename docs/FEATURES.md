# BeamNG Drive Mod Manager — feature reference

Mod categories, vehicle profiles, and configuration notes form the core of BeamNG Drive Mod Manager. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Mod categories | Content and resource groups, together with their configuration or organization details. |
| Vehicle profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Configuration notes | A dedicated section for configuration notes and the configuration details associated with that area. |

The project page follows the same section structure.
